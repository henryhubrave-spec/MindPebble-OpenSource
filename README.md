# MindPebble · 生活记录

面向 Android 手表与手机的生活记录助手，以 MIT 许可开放原创代码。手机 v0.5.4 / 手表 v0.4.5 是可安装的双端联动开发版：手表采集，手机接收、整理、搜索与管理；手机可按需下载模型并自动离线转写、做声纹候选标注；云端摘要与问答使用自行配置的 AI 服务，需逐次确认或明确授权自动任务范围。

手机 v0.4.3 新增无有效人声／LLM 杂音清理建议、多样本声纹补充、保留原文的声纹重新匹配。[使用与验证](docs/MINDPEBBLE_043.md)。

本轮手机 0.5.4：[自动逐小时总结、引用回听与后台补齐](docs/MINDPEBBLE_054.md)。

手机 0.5.3：[日期回看、详情三页签、本地搜索、引用问答、记忆三状态与选择性导出](docs/MINDPEBBLE_053.md)。

## 已接入的功能

| 手表（Android 8 / API 26 起） | 手机（Android 8 起） |
|---|---|
| “生活记录中”与小猫首页、明确麦克风状态 | 今日时光、语音回看、生活待办、高级设置四入口 |
| 开始、暂停、继续、停止并保存、重点标记 | 配对、蓝牙接收、哈希去重、删除防回流 |
| AAC 单声道、约十分钟分段、时间戳、离线缓存 | 原音播放、时间线、文字搜索、手动导入/纠正 |
| 可选心率、步数、气压、光照记录 | 默认关闭的离线 WebRTC VAD、原音/语音副本切换 |
| 约三十分钟批量同步，也可手动同步 | 可配置 ASR/LLM、摘要、记忆/待办草稿、来源问答与回顾 |
| 本地缓存清理由用户明确操作 | 记忆审核/停用、待办审核与本地提醒、ZIP 导出 |

不需要部署 Agent 服务器，不依赖 GMS。没有内置云端模型服务地址、API Key、遥测或第三方自动上传。离线资源由用户点击从固定公开地址下载，下载不发送录音。AI 请求会把确认范围内的音频或文字发送给配置的服务；配置公网服务意味着该请求的数据会离开局域网。

## 开始使用

1. 分别安装 `watch2-recorder-0.4.5-debug.apk` 与 `life-recorder-phone-0.5.4-debug.apk`。
2. 手机“高级设置”开启蓝牙接收，生成配对码；手表“连接手机 / 同步”选择系统已配对手机，输入 App 配对码。无需 Wi-Fi、热点或 IP。
3. 手表告知并取得相关人员同意后开始记录。完成的分段约每三十分钟批量尝试同步，也可手动立即同步；蓝牙断开仍保存在手表。
4. 手机可直接播放。到“高级设置 → 语音与智能处理”按需下载语音包，通过本机验证后选择使用，可开启自动离线转写。可独立下载声纹包、录入本人声音。云端摘要/问答另行配置 API，并逐次确认或明确授权自动任务。

详细步骤：[安装与配对](docs/GETTING_STARTED.md) · [构建](docs/BUILD.md) · [验证与限制](docs/VALIDATION.md)。

v0.4 新增：离线包下载/续传/校验与本机短测、独立本地队列、语音段时间范围与声纹候选、逐段纠正、日期/时段回看、手动待办、暖色原生界面与宽屏预览、手表中断检测与可读片段恢复。[使用与实现](docs/OFFLINE_VOICE.md)。

## 目前的边界

这是开发者预览版。兼容性基线为 Android 8 / API 26；厂商固件、后台限制、传感器和续航需要逐设备验证。分段采用停止/重启录制，不保证无缝。搜索为本地全文索引与常用相关词扩展；尚无向量语义搜索、可靠的跨天人物身份识别或逐词转写时间戳。声纹仅为语音段候选匹配，支持人工纠正，多人重叠不分离。语音唤醒实验在旧款 WATCH 2 上因推理积压未通过验收，默认关闭。

VAD 可能漏掉轻声或远处说话：默认关闭，先保留原音，只有另行确认才删除完整录音。心率不能直接解释为压力；光照不能解释为紫外线。缺测明确记录，不填零冒充观测。

## 结构与维护

- `apps/watch-legacy`：API 26 原生采集、采样与同步。
- `apps/phone`：原生 UI、SQLite、离线 VAD、可配置模型适配、本地任务队列。
- `packages/android-core`：安全蓝牙通道、加密令牌与本地安全工具。
- `packages/contracts`：跨端契约参考与迁移测试；当前运行时协议见架构文档。
- `tools`：统一构建、锁定依赖获取；`tests/android`：仅模拟器运行的集成测试。
- 设计资源：公开版仅保留许可明确的字体与原创宣传图；`services/agent`：历史说明，不是部署要求。
