# MindPebble 手机 App v0.5.4

已接入蓝牙接收、原音/派生音播放、VAD（默认关闭）、可配置 ASR/LLM、本地任务队列、来源问答/回顾、记忆审核、待办提醒、文字搜索和导出。无服务器 Agent 或 GMS 依赖。

参见根目录 [安装指南](../../docs/GETTING_STARTED.md)、[构建](../../docs/BUILD.md)、[验证限制](../../docs/VALIDATION.md)。包名 `org.diy.liferecorder`，minSdk26/target34。旧 v0.1 smoke 测试保留作历史参考；当前集成测试在根 `tests/android`。

新增按需离线包、自动本地转写、本人声纹候选与逐段纠正。参见 [离线语音说明](../../docs/OFFLINE_VOICE.md)。

新增清理建议、手表语句补充本人声纹和保留原文的重新匹配：[0.4.3 使用与验证](../../docs/MINDPEBBLE_043.md)。

录音理解整改：原文复制与语义分段、30 秒移动 ASR 上下文、工作站异步转写、原子事实、连续事件、记忆关联及分层复盘，见 [录音 Agent 工作流](../../docs/RECORDING_AGENT.md)。

## 0.5.2 连续理解与交互

移除待整理内容的固定时长聚合；回看改为后台读取与分页，提供完整记录／智能精选／重点摘要。完整原文逐句点击说话人，可调整、试听声音样本，登记人物声纹并合并所选发言。高级设置的声纹管理支持人物与独立样本维护。

增加有证据和上下文复核的 KEEP／COMPRESS／HIDE／REVIEW 过滤，可手动恢复。自动事件整理需明确开启并绑定服务配置；既有任务有阶段缓存和版本去重。手机弹窗、底部操作面板、日期时间选择器和按钮共用卵石风格组件。

实现、验证和已知边界见 [连续录音理解说明](../../docs/MINDPEBBLE_UNDERSTANDING.md)。

## 0.5.3 回看、搜索与导出

首页改为真实录音覆盖与重点；详情统一转写／重点／总结与固定播放器，增加本地日期搜索、逐结论引用问答、记忆三状态和总开关，以及五类内容的选择性导出。工作流采用文字 ZIP 交接。实现范围和实际边界见 [0.5.3 说明](../../docs/MINDPEBBLE_053.md)。

## 0.5.4 自动逐小时总结

首页和语音回看新增按日小时总结。独立开启后，在小时结束后自动整理逐句原文，校对或新转写会更新受影响时段，引用可回到原文与原声。支持后台调度、重试、来源失效和总结导出，详见 [0.5.4 说明](../../docs/MINDPEBBLE_054.md)。
