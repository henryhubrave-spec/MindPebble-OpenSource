# WATCH 2 手表 App v0.4.5

Android 8/API26 连续录音原型：“生活记录中”、明确麦克风状态、开始/暂停/继续/停止、约十分钟 AAC 分段、重点标记、离线缓存、可选传感器与蓝牙手机同步。

包名 `org.diy.watchrecorder`，min/target/compile26，保持旧表兼容。段间停止重启存在准备间隔，不保证无缝。意外中断会在用户仍开启持续记录时重试；手动暂停、停止会撤销恢复任务。详见 [恢复策略](../../docs/WATCH_RECOVERY_043.md)。

参见根目录 [安装配对](../../docs/GETTING_STARTED.md)、[构建](../../docs/BUILD.md)、[验证](../../docs/VALIDATION.md)。本目录 docs 下为旧独立原型历史说明，以根文档为准。

实验性离线唤醒词「你好小石头」（旧款 WATCH 2 因推理积压未通过验收，默认关闭）：开启后与持续录音共用 PCM 采集；暂停/停止会一并停止监听。见 [唤醒说明](../../docs/WATCH_WAKEWORD_044.md)。

0.4.5 节电调整：10 分钟录音分段、约30分钟批量同步、独立传感器计时与已封装文件哈希缓存。参见 [节电说明与验证](../../docs/WATCH_POWER_045.md)。
