# Stitch 页面实现与验收（2026-10-18）

界面采用暖色原生布局。公开快照不分发原始设计页面、来源未明确的标志或晨间图片；保留许可明确的字体。

按用户最新要求，**不下载、不打包本地 LLM**。摘要、待办提取、深度复盘、来源问答通过用户自行配置的 LLM API 处理。离线语音、声纹、VAD 与传感器阈值匹配保留在本机。

## 原生页面

使用设计中的暖白背景、陶土红、鼠尾草绿、细描边圆角卡片、品牌顶栏和固定底部导航。公开快照不含设计引用图片；Plus Jakarta Sans 字体按 OFL 随包分发。没有把远程 HTML 或 CDN 作为 App 运行界面。

| 页面 | 已接入交互 |
|---|---|
| 今日时光 | 真实读数/观察时间、传感器历史小图、30 秒呼吸练习、当日录音、API 提取待办、复盘、导入与统计 |
| 语音回看 | 日期选择、前后周切换、七日条与记录点、全部/清晨/午后/夜晚/高心率或标记筛选、原文搜索、事件分组、宽屏列表与预览 |
| 生活待办 | 语音候选审核、完成/重开、编辑、三类分类、原声来源、手动新增/手机录制/导入备忘、日期时间提醒、下一条真实提醒 |
| 情境提醒 | 可配置时刻、光照与心率阈值；15 分钟内有效观察才参与；手机通知；策略经现有蓝牙同步到手表，采集期间满足条件后每日最多微振一次 |
| 录音详情 | 真实 PCM 波形与点击跳转、播放/暂停、前后 10 秒、倍速、VAD 语音副本、原文/AI 要点/环境脉络切换、逐段纠正、API 待办建议审核、手表标记 |
| 高级设置 | OpenAI/Claude/DeepSeek/自建服务预填、端点/模型/密钥、温度滑块及保存、用户触发连通性测试、真实存储和模型状态、下载/续传/暂停/删除、传感器采样间隔、头像选择 |

API 连通性检测访问 `/models`；原生 Anthropic 适配使用 `/messages` 做短测试，界面明确提示可能产生少量费用。支持不提供 `/models` 的服务仍可配置和调用，但测速会报告该接口返回的状态。

录音复盘默认只发送原文。用户选择“结合情境深度复盘”后，确认对话框明确列出将发送所选录音的传感器观察；该次快照随任务保存。模型输出的情境复盘和日常恢复建议标为 AI。缺测不补零，不把心率直接当作压力、情绪或疲劳判断。

## 设计示例与真实能力

设计中的 2024 日期、86% 电量、72 bpm、示例录音、示例待办、模型下载百分比均不硬编码为真实状态。手表电量显示最近收到的观察，不宣称实时连接。没有将设计里的示例模型名称或“SensorContext-Fusion”虚构成已下载的模型。当前语音资源继续使用项目已有且可验证的资源目录；推理助手连接 API；情境融合使用可编辑的阈值规则。

“晨间唤醒”示例被替换为下一条实际设置的提醒。体表温升切换白噪音是设计中的一条示例待办文本，不是这套界面定义的自动化功能。

## 验证

- 手机、手表开发 APK 均由项目工具链构建并验证签名。新增功能、API、手机录音与原有同步/待办/契约合计 50 项断言通过。
- 新增手机 `phase=stitch-memo` 使用禁用主机音频的模拟器验证真实录制、解码与入库；`phase=stitch` 覆盖缺测/过期/未来时间拒绝、读数读取、通知送达、草稿审核与温度快照。
- 新增 `phase=stitch-provider` 使用模拟器本机合成 HTTP 服务，覆盖实际请求、参数传递、解析、重定向拒绝与配置版本保护。
- 手表 `phase=stitch` 覆盖缺测、过期、有效条件、每日去重与关闭规则。
- 可复现 UI 检查脚本为 `tests/android/verify-stitch-ui.py` 与 `verify-stitch-adaptive.py`，仅允许专用 ranchu 模拟器。UI 检查与截图位于 `outputs/stitch-preview/`，只使用模拟器合成数据。

新增手表微振与采样间隔尚需实体设备验收；真实服务兼容性需要用户自行配置服务后验证。Android 的非精确闹钟与厂商后台策略可能延后提醒，不承诺准点到秒。没有向个人设备安装或发起真实付费模型请求。
