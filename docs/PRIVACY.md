# 隐私与数据流

- 手表录音和可选传感器观察保存在手表；通过已配对的蓝牙链路传到手机。离线时保留原件。
- 手机录音、文字、记忆和待办保存在应用私有目录。没有额外全库或全音频加密，不承诺能抵御已解锁、root 或被控制的设备。
- 离线 ASR、VAD、声纹推理在手机运行。资源下载访问固定公开下载站，会产生正常网络元信息，不发送录音。
- 用户配置的云端 ASR/LLM 会收到所选音频或文字；逐次确认，或在明确授权的自动任务范围内发送。撤回自动整理授权可阻止后续自动请求；已发送到服务商的数据需按该服务商规则处理。不能把整套流程称作永不联网或完全离线 AI。
- Key 与配对令牌经 Android Keystore 保护，不进入项目服务器或导出包。项目没有内置遥测服务。
- 导出及备份可包含音频、文字和声纹相关个人信息，需自行妥善保管；分享前另做脱敏。提交 Issue 不要上传真实录音、Key、原始日志或个人地址。

请在相关人员知情同意的场景使用；AI 结果和声纹候选需要人工核对。健康传感器数据不能直接用于诊断或推断情绪。
