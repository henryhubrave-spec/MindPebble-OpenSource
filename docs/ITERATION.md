# 迭代与发布

当前为手机 v0.5.4 / 手表 v0.4.5 源码预览。手表、手机与共享协议在单仓库协作，保持 API 26 兼容，统一脚本构建；依赖锁版本/哈希，迁移使用 SQLite 版本。

发布前先跑契约、保留区间与模拟器集成检查，再核对签名与版本。新增协议字段应兼容缺省值，改变语义时增加版本并明确拒绝不支持客户端。数据库迁移单向增量，删除与升级先导出用户数据。严禁提交私人音频、API Key 或签名私钥。

后续实机验收：WATCH 2 Android 8、MIX Fold 4 展开/折叠与 HyperOS 后台；蓝牙断线补传、重新系统配对、长录音、缺传感器、低存储与低电量；真实用户配置 ASR/LLM 的协议兼容性。现阶段 debug 包不作为稳定商店版本。

后续增强：逐句时间戳与说话人标签、向量语义搜索、整包恢复、稳定蓝牙重连、多手表和更完整无障碍/大字体适配。Speakr 可作为未来导出或 API 适配对象，不在当前本地 Agent 的运行依赖中。
