# v0.4 离线语音与持续记录

## 使用

安装 `outputs/life-recorder-phone-0.4.0-debug.apk` 与 `outputs/watch2-recorder-0.4.0-debug.apk`，沿用现有 App 数据与签名，不卸载旧版。

手机：高级设置 → 管理资源下载与自动整理。

1. 按设备初筛推荐，下载轻量或标准语音包。声纹识别包独立下载、两档共用。模型不随基础 APK 分发。
2. 可选原站 `huggingface.co` 或国内镜像 `hf-mirror.com`；界面显示实际下载主机。两种源使用同一固定文件哈希。下载支持暂停、继续、失败后恢复；重定向只接受 HTTPS。
3. 完成后自动核对 SHA-256 并运行包内公开测试音频，成功才显示可用。点击“使用这个方案（新任务）”，再开启自动整理。
4. 默认仅充电时自动处理；用户可关闭该限制。低电、低空间、内存紧张、明显发热、省电模式会延后。系统后台调度和厂商限制可能延迟执行。手动逐段任务也受电量、空间和热状态保护。
5. 如需本人识别，下载声纹包后选择 5–30 秒只有本人说话的清晰样本。本机生成声纹后删除临时样本，声纹通过 Android Keystore AES-GCM 封装；可独立删除。
6. 在手表明确开启持续记录。保持可见麦克风状态，可熄屏采集、标记、暂停、停止并保存。手机端按约五分钟完成段接收并自动处理。断连时手表缓存，周期任务尽力补传；不承诺实时文字或无缝音频。

## 实现

- 运行库：sherpa-onnx 1.13.8，官方发布 AAR SHA-256 `633c24321e06b1fe79feafa03ea16cbc0f8a286641e2da3559bac91bdb13bd96`；JitPack 获取物与该官方哈希一致。ONNX Runtime 1.28.2，CPU provider，最多两线程。手机仍 minSdk26，无 GMS 或 Agent 服务器要求。
- 轻量包：Zipformer Small CTC 中文 INT8。包含模型、词表、BPE 与公开测试语音，共 26,790,532 字节（25.5 MiB）。
- 标准包：SenseVoiceSmall INT8，普通话/粤语/英/日/韩。模型、词表与公开测试语音共 239,728,723 字节（228.6 MiB）。
- 声纹包：3D-Speaker CAM++ 中英文高级模型，与公开测试语音共 28,460,810 字节（27.1 MiB）。镜像权重与 GitHub 官方 checksum.txt 的 SHA-256 交叉核对一致。
- 每包固定提交版本、每文件大小与哈希，见 App 资源 `offline-catalog.json`。下载区与安装区隔离，安装完成标记原子提交。未通过运行测试的包不能选择。
- 全部模型是可选数据文件，不下载可执行代码。删除模型不删除录音、已保存转写或声纹；删除当前 ASR 包关闭自动处理，取消依赖该包的排队任务。
- `local_asr` 队列由独立 `OfflineJobService` 执行。自动任务不启动 `AgentService` 或 ProviderClient 请求。API 摘要、问答与回顾保持用户确认。
- 解码为 16kHz 单声道 PCM，WebRTC VAD 寻找语音区间，500ms 前缓冲、800ms 后缓冲，最长约12秒语音段。VAD 只用于处理，不删除原音。不保证轻声/远场召回或逐词时间戳。
- 结果保留语音段起止时间、文本、声纹标签、模型版本及耗时。播放精简资产时转回原始时间。不是多人重叠语音分离；12秒切段仍可能包含多人，标签仅为候选。
- 本人相似度初始阈值 0.72，未经真实佩戴场景校准，显示“可能是我”。其他语音段做录音内聚类，不自动跨天确认姓名。人工纠正以版本号防覆盖；原始模型结果留在任务中。
- SQLite v4→v6 增量迁移，保留原文和来源待办，新增语音结果/原文修订号；独立手动待办允许无录音来源。删除来源同时取消关联离线任务。
- 本地任务进程中断后按文件重新排队，不重复调用云服务；在原文或音频发生修改后不覆盖人工结果。系统调度暂停时会重算当前文件，不保存模型中间状态。
- 资源推荐结合内存初筛、标准包短测与持续任务耗时。连续较慢会推荐轻量包，不擅自下载或替换用户已选模型；热状态/内存保护会延后执行。
- 同一采集会话按日期、15分钟实际间隔及90分钟窗口保守分组，不宣称主题语义聚类或无缝播放。语音回看保留日期、时段和文字/标签搜索，展开宽屏使用列表/预览双栏。

## 手表兼容性

录音元数据新增可选 `gap_before_ms`，旧接收方忽略该字段即可；它是录制启动间隔，不是精确音频缺口测量。协议 MAGIC 与配对凭据均不改变。

新增采集启动日志。App 冷启动会报告上次录音中断；仅尝试恢复有日志且容器可读的片段，无法读取的临时文件保留。不保证能修复系统强杀导致缺少 MP4 索引的录音。冷启动不会自动打开麦克风，用户手动重新开启。

## 许可

运行库与模型分别按其许可分发。完整许可位于 `licenses/`，随 App 放入 `assets/licenses/`；来源与署名同时显示在资源页。SenseVoice 权重使用 FunASR Model Open Source License Agreement v1.1，不能用转换工具的 Apache/MIT 许可替代。原音、Key、本人声纹和测试设备配对凭证不提交到仓库。

## 当前验证边界

模拟器上的公开短样本速度不能代表真实手机吞吐、准确率或耗电。尚待实体 WATCH2 / MIX Fold4 验收：新段自动蓝牙同步、射频断线重连、锁屏长时处理、真实佩戴中文噪声/轻声/多人场景、声纹误认漏认、传感器与全天续航。当前为本地 debug 开发包，未发布应用商店。
