# ADR 0004：只用蓝牙同步

2026-10-18，应用户明确选择，v0.3 用 Android 安全 RFCOMM 替代 v0.2 的局域网 TLS。日常不使用 Wi-Fi/热点，不保留 App Wi-Fi 同步入口或 TCP 监听。调试安装的 ADB 网络是独立开发通道。

复用原有数据格式、稳定设备/文件身份、哈希校验、耐久回执与遗忘机制。手机额外绑定实际 RFCOMM 对端地址，配对令牌仍加密保存。使用系统已配对列表，无扫描和定位权限，无 GMS。手机 connectedDevice 前台服务需附近设备权限；手表后台周期任务移除网络约束，否则没有 Wi-Fi 时蓝牙同步也不会被调度。

未引入 BLE/GATT 大文件分片，也不引入依赖 GMS 的 Wear Data Layer。RFCOMM 是否被 WATCH 2 固件支持、与现有 Wear OS 连接共存，以及小米锁屏后台行为，需要实体双端验证。流协议模拟测试不等于射频验证。
