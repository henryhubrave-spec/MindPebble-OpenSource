# ADR 0002：双端本地数据与手机内Agent

状态：按用户2026-10-17明确要求采用；取代ADR0001中的服务端、部署Profile和服务端保存模型Key三项。

- 当前只做手表与手机，不部署Agent服务器，不要求网关、NAS、云账号或PostgreSQL。
- Agent编排、检索、记忆、待办、存储与索引在手机；仅明确的转写/分析任务向用户填写的API发送最小所需资料。ASR和LLM分别配置协议、地址、模型、API Key。
- 没有AI也能导入、保存、播放和管理。默认不云备份、不遥测、不自动上传；模型API接收方是否为本地，由用户实际地址决定。
- Key在手机Keystore保护下加密保存，不入Git/导出/日志。
- VAD控制入口放手机设置，默认关闭，完整音频为默认。保存偏好不代表手机引擎或手表已生效；设备ACK与能力明确显示，旧音频不自动改写。
- 耗电基线已结束，不再作为进度阻塞；没有终点数据就不补写耗电率。

代价：手机承接持久队列、进程恢复、数据库迁移、模型适配与隐私边界，需验证HyperOS行为。服务端旧目录只保留历史说明；旧协议兼容项不等于当前部署要求。

首切片使用现有离线Android工具链和Java/Views以得到可检验APK；它是可替换的原生UI基线。后续Compose迁移单独锁定依赖与验收，不以架构图冒充运行能力。
