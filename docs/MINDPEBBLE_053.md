# MindPebble 0.5.3 · 回看、搜索与导出

后续 0.5.4 已补齐自动逐小时总结，见 [0.5.4 说明](MINDPEBBLE_054.md)。以下为 0.5.3 当时的实现范围。

本轮参照用户提供的《Auday 1.0.5 拉片与需求功能详情》，在已有 Android 双端能力上整理手机体验。附件中的验收建议和宣传数字作为参考材料，不是本 App 的性能实测。保留项目原有未提交改动，本轮不更新实体设备。

## 已实现的交互

- 今日时光展示真实已同步覆盖时长、录音数、标记数、待转写数与 24 小时覆盖条。跨午夜按当天裁剪，重叠录音不重复累计；空白时段不推断为录音故障。同步结束和返回首页后刷新。
- 语音回看默认选定当天，七日条与日期选择器切换日期；保留完整记录、智能精选和重点摘要。我的标记单独展示可回听卡片，与心率读数分开。
- 单条与连续录音统一为转写／重点／总结。固定播放器支持真实波形、进度、前后 15 秒和倍速；逐句点击回听，当前句高亮。VAD 精简副本仍以原始录音时间定位，已丢弃音频不会伪装成可播放。
- 搜索在本机建立可重建索引，支持关键词、常用相关表达、日期范围、按日分组、命中高亮与来源跳转。标题、转写、已保存记忆的修订与来源删除会更新索引。
- 搜索结果勾选来源后可明确发起问答。每条结论校验引用原句、来源编号和时间范围，点击引用回听；追问限定在所选来源。没有可核对证据时明确说明。原文只有人工无时间文本时，仍可检索查看，但不会伪造时间引用。
- 长期记忆按待确认／已保存／已停用切换，支持编辑、保存、停用与整体关闭。关闭后保留历史资料；旧排队请求使用的记忆或策略已变更时，需要重新发起。
- 导出按日期或单条录音选择原音、带时间码转写、手动重点、总结、每日回顾。ZIP 内提供通用 TXT／Markdown／JSON、来源索引、类别数量与跳过原因；支持进度、取消和失败清理。工作流入口提供文字资料包交给电脑 Agent。
- 转写设置集中呈现轻量中文、多语言离线和云端／自建方式，变更只作用于后续任务。旧文字重转写仍需在详情主动操作。

## 删除与合并的体验

首页删除装饰风景图、呼吸练习和大块传感器仪表；环境线索继续服务于具体录音。待办页删除前置的环境提醒大卡，保留待办确认和完成操作，回顾提醒移至设置。详情页的重复处理／校对／存储操作合并进“更多”与单个校对入口。搜索与问答合并到统一页面，去掉未命中时默认选择最近记录的旧问答入口。

UI 使用现有 Serene Hearth 规范：暖白底色、陶土色操作、鼠尾草绿状态、600 字重标题、扁平圆角表面；宽屏正文限制宽度，播放器与滚动内容分离。

## 与竞品的对应和边界

| 参考功能 | 本 App 状态 |
|---|---|
| F01 长时录音、F02 标记、F03 原音保留 | 复用已有手表采集、恢复、标记与保留策略；本轮补齐手机标记消费与展示，不重新宣称续航验收 |
| F04 日期归档、F05 逐句转写 | 本轮整合日期、覆盖统计、详情三页签与准确回听；时段过滤保留现有早／午／晚，未照搬逐小时三层导航 |
| F06 本人声纹 | 复用现有声纹登记、人物／样本管理与逐段纠正，不承诺准确率 |
| F07 重点、F08 时段总结、F09 每日回顾 | 标记重点、所选录音／事件总结、已有来源日回顾均可查看；未新增每天自动生成的 24 份小时总结或生成封面 |
| F10 上下文 | 复用手表实际支持并授权的心率、光线、气压、步数；未新增 Apple Health、HRV、睡眠或位置轨迹，不推断情绪 |
| F11 搜索 | 本地全文索引与相关词扩展，尚无向量 embedding；未验证附件的万条 800ms 或 Top3 命中率指标 |
| F12 问答引用 | 本轮加入逐结论引用校验、可回听时间与限定来源追问；当前完整响应后展示，未做流式输出 |
| F13 长期记忆 | 三状态、来源、编辑／停用与总开关；候选不会自动采用 |
| F14 导出 | 五类内容可选、日期范围、来源清单、进度和取消；按录音开始日期选择整段，不裁音频；取消／重建页面后重新导出，无分卷或断点恢复 |
| F15 电脑工作流 | 实现用户选择的文字 ZIP 交接；尚无竞品的局域网加密配对、手机监听服务或自动 Skill 安装 |
| F16 转写引擎 | 用真实可用的轻量、多语言及自选服务替代 iPhone 专属档位，不将多语言档宣传为准确率保证 |

导出保存位置由 Android 系统文件选择器决定。第三方文件提供者可能自行同步到其服务；App 不主动发起资料上传。API Key 不在选择性导出内。历史全量备份函数保留兼容，本轮可见入口以选择性导出为主，尚无 ZIP 整包恢复。

## 构建和验证

手机版本 0.5.3（versionCode 13），沿用原包名和开发签名；输出 `outputs/life-recorder-phone-0.5.3-debug.apk`。本轮没有改动手表采集控制，也没有安装到实体手机或手表。

专项测试均在 `auday-review` Android 14 ranchu 一次性模拟器运行，宿主音频禁用，数据为合成 WAV、原文及本机模拟服务。截图位于 `outputs/mindpebble-0.5.3/`。

- `auday053 -e ui true`：日覆盖、跨午夜／重叠／夏令时边界、真实首页统计、日期回看、详情、记忆、搜索与导出页面。
- `detail-playback053`：原音与 VAD 时间映射、被省略时间、标记去重、逐句边界。
- `search-memory053`：索引修订、日期范围、引用校验、记忆关闭与旧请求失效。
- 独立 `ExportTests`：选择范围、五类内容、目录安全、凭证排除、取消、来源变更与跨范围结论。

未测试实体设备的功耗、全天连续录音、真实声纹准确率、远场转写质量或真实外部 LLM 效果。模拟器原声跳转验证不能当作附件中 0.3 秒定位等实机指标。

本轮最终专项与原有回归合计 334 项断言通过（相同阶段重复运行不重复计数）。小屏截图检查发现并修复了播放按钮因图标挤压导致的文字换行截断。实际记录见 [验证记录](VALIDATION.md)。
