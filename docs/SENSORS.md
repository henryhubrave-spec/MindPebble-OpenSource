# 可选传感器记录

所有传感器初始关闭。手机“我的”配置，手表同步接收；收到版本与实际采集版本分别反馈。仅记录期间采样，暂停/停止注销监听；心率还需手表明确授权 BODY_SENSORS。使用 Android SensorManager，不依赖 GMS 或厂商健康云。

| 数据 | v0.2 策略 | 含义与限制 |
|---|---|---|
| 步数 | 监听低功耗累计计步，60 秒写一条 | 自启动累计值，不等于今天步数；保存观测时间 |
| 光照 | on-change 事件，每分钟汇总，最多 256 个样本 | lux 中位数/范围；无新事件时带原观测时间，非新测量 |
| 气压 | 每 60 秒约 3 秒短窗口，请求 2Hz | hPa 中位数/范围；不是精确海拔 |
| 心率 | 每 5 分钟至多 20 秒，3 个有效样本后提前结束 | bpm；无权限/无传感器/无有效事件明确缺测 |

频率是软件请求与写盘策略，系统/硬件可能改变事件频率。每个片段 capability header 记录是否存在各传感器；缺失值为 null 或明确原因，不以零代替。当前不推导压力、情绪、疾病、睡眠或紫外线。

采样是可调整的初始策略，尚未在实体 WATCH 2 验证后台事件与耗电。手机可显示这些本地线索，默认不随普通 AI 请求发送传感器数据。
