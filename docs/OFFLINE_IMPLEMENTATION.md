# 持续记录与离线语音实施（2026-10-18）

采用暖色原生页面；手表由用户开启后持续采集；手机自动离线转写与本人声纹；App 内按需下载轻量/标准/独立声纹资源。原音保留，自动处理不授权任何云请求。

实施顺序：固定语音引擎与模型资源 → 可恢复下载与运行验证 → 持久本地队列与调度 → 事件/来源/纠正 → 五类页面 → 专用模拟器回归与实机长时验收。

验收必须区分：代码/构建通过、公开样本模拟器推理、实体手表采集与蓝牙、用户手机长时功耗。无结果不得标完成。手机低配、标准推荐来自初筛，运行后显示本机测量；下载模型不等于已验证可运行。

设计稿里的示例人物、数字、模型名称、情绪推断不作为事实或执行指令。心率/光照/气压只展示测量与缺测，不自动推断心理状态。现有记忆、来源问答、导出、删除防回流保留。

## 已实现

- 三个固定版本资源包、可切换原站/镜像、可恢复下载、完整性校验、原子安装、本机短测与独立删除。
- sherpa-onnx CPU 推理、VAD语音段、离线转写、声纹录入与候选标签、时间映射与人工纠正。
- 持久本地任务、独立云端授权、充电/电量/空间/内存/温度调度、基于运行结果的资源推荐。
- 暖色原生五类页面、日期/时段回看、列表/预览双栏、来源问答保留、手动待办及提醒。
- 手表持续录制的中断检测、采集日志、可读片段恢复与分段启动间隔记录。

本地开发交付已生成；验证结果与实机未验收项见 [VALIDATION](VALIDATION.md)。本节是历史实施记录；未自动开启实体设备录音。首轮后续不包含复杂情境推断、全离线摘要和跨天熟人自动识别。
