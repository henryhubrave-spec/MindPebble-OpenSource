# 产品方向与验收目标

本文件包含长期目标；v0.4.0 已实现范围与限制以根 README、VALIDATION 为准。主题自动聚类、向量语义搜索、人物视图、压力推断等尚未实现。

MindPebble 面向允许侧载的 Android 手表（API 26 起）与 Android 手机。双端本地数据、手机内 Agent 与可配置 ASR/LLM API；不要求部署 Agent 服务。兼容性需逐设备验证。

## 核心体验

手表负责随手记录与标记；手机负责把一天整理成可以回看的事件；手机内Agent负责整理、检索和管理；只有转写、总结等必要AI任务才请求用户配置的模型API。录音关闭、网络断开、模型服务不可用时，仍应能保留录音并浏览本地已保存的内容。

一次典型流程：

1. 用户确认知情同意，在手表开始；屏幕与通知清楚显示录音状态。
2. 重要时刻点“标记”，不必掏手机。暂停和停止保存始终可发现。
3. 每5分钟形成传输片段；手机根据时间、暂停、主题和用户标记组织成“项目讨论”等事件。系统不能因为语义相似就把真实中断显示成连续音频。
4. 手机展示“已到手机/待转写/转写中/可查看”等真实阶段，而不是一个笼统进度条。
5. 用户打开事件，先读短摘要和待办，再点来源回到原文和原音频。
6. 晚上得到简短回顾：“今天的重要决定、尚未完成的承诺、新想法”；事实和AI解释分开呈现。
7. 用户可问“上次我们决定了什么”，答案必须带可点开的来源；没有证据时明确回答未找到。

## 手机四个主入口

- **今天**：日期、最新设备状态、录音覆盖条、按事件组织的时间线。把重要事项排在前面；纯技术日志放设备详情。
- **回忆**：全文/语义搜索、来源卡片、人物/项目视图、可编辑的长期事实。身份未确认时使用“说话人1”，不猜名字。
- **待办**：从会话提取的草稿，显示原句、建议负责人/截止时间。用户接受或编辑后才成为正式任务；执行连接器另有授权。
- **我的**：设备、同步与存储、AI API配置、数据导出与删除、权限和通知。API密钥输入可遮罩，不进入日志。

AI问答作为“回忆”页入口及事件内操作，避免一打开就是空白聊天框。API设置留在“我的”，不占据日常内容页面。

## 手表首屏

待开始 / 生活记录中 / 记录已暂停 / 错误四种状态。生活记录中使用原创静态小伙伴与轻松文案，同时明确显示“麦克风已开启”；VAD等待说话不隐藏此状态。展示计时、语音留存量，以及标记、暂停、停止保存三个动作。红色仅表示录音或危险操作；正常同步使用安静的中性色。

低电/低空间时先明确提示，再按已定义策略停止保存；不靠隐藏手势完成唯一的停止操作。长按或滑动只能是快捷方式。状态变化可用轻振反馈，后续必须实测能否关闭及额外耗电。

## 新增采集要求

VAD入口放手机设置，默认关闭，默认完整保存。v0.2 已接入手机本地引擎与策略传输；开启不自动修改旧文件。配套首尾缓冲与时间映射，原件默认保留；节省手表存储需明确清理缓存。离线实验见[SPEECH_RETENTION](SPEECH_RETENTION.md)。

步数、间歇心率、气压与光照使用可配置策略，默认候选频率和缺测处理见[SENSORS](SENSORS.md)。采集值和模型推断分离；手机支持按环境变化回到附近原文。

## 本地处理与AI边界

默认无需账号或服务器，采集、导入、播放、整理与索引在本地。Agent编排、记忆管理与待办留在手机；云备份、遥测与自动AI处理默认关闭。

只有用户启动会议转写、总结、分析或问答等AI任务时，才向用户分别配置的ASR/LLM地址发起请求。转写发送选定音频；分析发送所需原文与用户选定上下文，不默认附健康、位置和全部历史。界面显示真实接收主机与资料范围，不能将远程模型请求描述成完全离线。

本地关键词检索不请求AI；语义检索以后采用可选端侧模型，暂不调用云Embedding。普通LLM接口不等于支持音频转写；每种能力分别适配与验证。手机localhost指本机，不是Mac。

## 记忆与建议的约束

- 原始音频、转写、人工纠正、AI结论分别保存；纠正后可重算，不覆盖原始证据。
- 人物、偏好和承诺带来源与有效时间；矛盾信息进入待审核状态。
- 不将“心率升高”等同于焦虑，也不将缺少测量当作正常。
- 主动建议从“待办到期、用户标记复盘”开始；有来源、可解释、可关闭、可设安静时段。
- 原音频的保留期限由用户选择；删除前明确哪些来源将不能回放。标记重点也不能覆盖用户的删除意愿。
- 没有模型服务时只显示实际录音覆盖，不造“信息密度”“压力”等分析图。

## 验收指标

可靠性：断网/杀进程/重复传输不丢已确认保存的文件；缺口可见；已录音未转写与未录音分开显示。

可用性：首次安装能完成一段录音→手机播放；手表停止保存无需滚动找按钮；中文大字号可用；手机展开屏不拉长单列。

AI质量：摘要关键结论有来源；自然语言问答能回到原文；无来源的任务不会自动执行；对转写错误支持纠正后重算。

功耗：分别对照测量同步、传感器和分析，不能同时开启后把额外耗电归因于录音。已有耗电测试已结束，不阻塞开发，也不编造终点结果。

## v0.4 已批准并实施的调整

手机导航为今日时光、语音回看、生活待办、高级设置；长期记忆与有来源问答保留在语音回看入口。手表用户开启后持续采集；手机模型按需下载、验证后可自动离线转写与声纹候选标注。新增的能力与实际边界见 [离线语音](OFFLINE_VOICE.md)。原文、原音及人工纠正继续分开管理；情绪推断不按设计稿示例实现。
