# 手表 0.4.4：语音唤醒实验（默认关闭）

## 使用

在手表 MindPebble 页面向下找到「语音唤醒」，勾选开启并保存。持续记录开启、模型就绪后，熄屏喊「你好小石头」会震动、亮屏并打开主界面；连续触发间隔至少 10 秒。亮屏请求有时限，不保持屏幕常亮。设置默认关闭，需要使用者主动选择。

手动暂停或停止记录也停止唤醒监听，不会隐瞒继续使用麦克风。需要先手动开始记录，才可用唤醒词；进程被系统强行停止或通话占用麦克风时无法保证唤醒。唤醒只打开界面，不执行语音命令，不代替系统锁屏认证。

## 实现与资源

- 原 MediaRecorder 路径在语音唤醒关闭时保留。开启时使用 AudioRecord 单次采集 16kHz 单声道 PCM，编码 AAC/M4A 和离线关键词检测共用数据，不能再启动第二个麦克风客户端。
- AAC 编码优先执行，检测使用独立线程、有界队列和一个模型线程；初始化期间不堆积声音，推理持续积压会暂停唤醒并提示不可用，录音继续。切段保持原约五分钟策略，存在重新准备的间隔。
- 暂停/停止同步撤销持续记录意图，释放采集并停止关键词检测。既有来电等待、错误重试、服务恢复、标记、蓝牙与归档继续使用。PCM 采集异常时已完成封装的片段仍保存，无法完成的临时文件保留。
- 触发前再次检查功能开关、持续记录意图和服务状态；打开应用不改写手动暂停/停止。屏幕唤醒锁为 2 秒、界面保持亮屏上限 10 秒，不申请系统助手或热词特权。
- 离线模型采用作者发布的 WenetSpeech 3.3M INT8 KWS，权重约 4.8 MiB，包含在当前手表 APK；含运行库的 APK 约 26 MiB。这与手机可下载 ASR/声纹资源包独立。手表未新增 INTERNET 权限。
- 模型逐文件固定提交和 SHA-256，见 `tools/watch-wakeword-model.lock.json`。作者 README 标记 Apache License 2.0；模型 README 与 sherpa-onnx、ONNX Runtime、Kotlin 许可及来源随包保留。

官方模型与自定义关键词说明：https://k2-fsa.github.io/sherpa/onnx/kws/ 。该文档证明提供该能力，不等同于这块旧表的性能或续航保证。

其他语音助手可能占用麦克风。MindPebble 不自动调整其他应用设置。

## 验证范围

禁用主机音频的独立 Android14 ranchu 模拟器：共享采集实际 AAC 编码和解码、暂停/继续/停止、采集错误重试与过期恢复保护，唤醒打开界面、暂停后拒绝唤醒，真实 INT8 模型识别本机合成「你好小石头」，无关语句和静音未触发。旧录音路径及归档、蓝牙协议一并回归。

合成语音检查不是准确率评估；真实声线、距离、环境噪声、误触率、屏幕与厂商后台行为、长时发热和额外耗电需要实机验证。暂不承诺随叫随醒或低功耗 DSP 常开。


## 兼容性限制

旧款 WATCH 2 实测发生推理积压，保护逻辑停止检测而保留录音。未通过可用性验收，不宣传为稳定支持。建议保持关闭；没有可靠的误触率或耗电增幅指标。升级前必须在同一控制流程核对录音暂停及保存成功，失败即终止。
