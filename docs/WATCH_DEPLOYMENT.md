# 从零把 MindPebble 装到 Android 手表

适合愿意使用电脑和 ADB 的使用者。最低 Android 8 / API 26；主要面向旧款 Android/Wear OS 手表，不支持 Apple Watch，也不保证所有品牌固件可用。先确认手表允许安装第三方 Android APK。手机也需要 Android 8 或以上。

## 1. 准备安装包和电脑

源码构建见 [BUILD](BUILD.md)。当前手机包 `life-recorder-phone-0.5.4-debug.apk`，手表包 `watch2-recorder-0.4.5-debug.apk`。公开源码没有附带个人开发签名私钥；自行构建的签名与其他来源的包通常不同。

安装 Android SDK Platform Tools，终端运行 `adb version`。macOS 使用 Codex 连接设备前，在「系统设置 → 隐私与安全性 → 本地网络」确认 Codex 已开启；使用其他终端时核对相应程序权限。调试电脑和手表在同一可信 Wi-Fi，勿使用访客隔离网络。

## 2. 开启手表开发者模式

1. 手表打开「设置 → 系统 → 关于」（部分固件直接叫「关于」）。
2. 找到「版本号 / Build number」，连续点约 7 次；如要求 PIN，输入设备解锁 PIN。看到“您已处于开发者模式”后返回设置。
3. 打开新出现的「开发者选项」，开启「ADB 调试 / Android 调试」。
4. 旧款 WATCH 2 常见为「通过 WLAN 调试 / Debug over Wi-Fi」，开启后记下页面显示的 IP 和端口。新款系统可能叫「无线调试」，需先配对，见下一节。菜单名称随固件变化，缺少该选项时不要套用别款设备地址。
5. 连接时手表会弹出调试授权，核对是自己的电脑再允许。USB 数据底座可用时也可通过 USB 调试连接。

## 3. 连接电脑

以下大写内容是占位符，替换为手表实际显示值，不要原样输入。

旧款 WLAN 调试：

```sh
adb connect WATCH_IP:DEBUG_PORT
adb devices -l
```

新版 Android 无线调试：在手表选择「使用配对码配对设备」，先使用该页的配对端口和临时码，再使用主无线调试页的连接端口；两种端口可能不同。

```sh
adb pair WATCH_IP:PAIR_PORT
adb connect WATCH_IP:DEBUG_PORT
adb devices -l
```

列表状态应为 `device`。`unauthorized`：查看表上授权弹窗；`offline`：核对 Wi-Fi、端口与调试开关后重连。多个设备在线时，后续命令必须指定 `-s WATCH_SERIAL`，其值取自 `adb devices` 第一列。不要公开包含个人 IP、序列号或蓝牙地址的终端截图。

## 4. 首次安装

先确认尚未安装：

```sh
adb -s WATCH_SERIAL shell pm path org.diy.watchrecorder
```

只有返回中没有 `package:` 路径时，才执行首次安装：

```sh
adb -s WATCH_SERIAL install outputs/watch2-recorder-0.4.5-debug.apk
```

显示 `Success` 后，在手表应用列表打开 MindPebble，按提示授予麦克风权限；需要心率功能时再授予传感器权限。手机通过文件管理器安装手机 APK，仅对该安装来源临时允许安装。不要关闭整机安全保护。

**已有安装的升级**：不要直接添加 `-r` 执行覆盖。必须使用适配该版本的单一控制流程，依次确认录音已暂停、当前片段成功保存且元数据/容器有效，再调用安装；任一检查失败立即终止。当前公开包没有可跨固件保证这些状态检查的通用升级器，因此本教程不提供自动覆盖命令。签名不一致时先在 App 中备份并验证能恢复；不要直接卸载旧 App，卸载会丢失私有数据。

## 5. 系统配对与 App 配对

1. 手机、手表打开蓝牙，在系统或配套 Wear OS App 中完成系统配对。
2. 手机 MindPebble → 高级设置 → 设备与采集 → 手表连接与文件接收 → 开启蓝牙接收。Android 12+ 允许“附近设备”；按提示允许接收通知。
3. 手机生成八位配对码；有效五分钟、一次使用。手表打开「连接手机 / 同步」，选择已配对手机，核对设备名称后输入 App 配对码。
4. 手表点击「立即蓝牙同步 / 更新设置」。系统配对与 App 配对是两步，不能互相替代。

## 6. 第一次记录与回听

1. 先取得参与者知情同意，在手表点击开始，确认界面显示麦克风使用状态。
2. 试录一小段，点重点标记，再暂停；确认保存成功。手动同步，手机打开今日时光并试听。
3. 点击继续，观察后台记录。0.4.5 约十分钟一段，约三十分钟批量同步；如需立即查看，先暂停保存，再手动同步。断开蓝牙仍缓存在手表。
4. 手机按需下载语音包，通过本机验证后启用离线转写；声纹仅作候选标注。VAD 默认关闭，开启先保留原音，轻声可能漏检。
5. 云端摘要、问答需自行配置模型地址、模型名和 Key。逐次确认或明确授权的自动整理会向该服务发送确认范围内的内容，详见 [隐私说明](PRIVACY.md)。
6. 手机确认副本可播放并完成备份后，再考虑清理手表缓存。删除、清理和导出前阅读确认提示。

## 7. 排查与结束调试

找不到手机：先核对系统蓝牙配对；不能同步：重开手机接收并在表上手动重试；后台延迟：检查厂商电池策略，不把前台通知当作永不被杀的保证。权限拒绝可回系统 App 权限重新开启。麦克风冲突、低电量和存储不足会影响记录；损坏临时片段不保证恢复。

使用结束运行 `adb disconnect WATCH_IP:DEBUG_PORT`，在手表关闭无线/ADB 调试。日常同步只用蓝牙，不需要保持电脑、Wi-Fi 调试或同一 Wi-Fi。

参考：[Android ADB 官方文档](https://developer.android.com/tools/adb)、[Wear OS 调试文档](https://developer.android.com/training/wearables/get-started/debugging)。
