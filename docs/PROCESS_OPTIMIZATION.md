# 流程优化（2026-11-01）

本轮基于手机 0.5.4 开发工作区，数据库升级为 v13；双端蓝牙协议不变。

## 授权与快照

- 关闭自动语义整理时先撤回授权，再取消自动排队/运行任务；每次 Provider 请求的取消检查都会检查授权。已发送到服务的内容无法撤回。
- 手动重试创建独立的手动任务，不依赖自动整理开关。
- 分析任务入队时固定原文、相关记忆、连续事件、相邻录音边界文字和音频质量统计。执行时只校验、不重新检索扩大范围。旧任务缺少完整快照时需重新确认。
- 配置、原文或上下文变化时拒绝旧证据。显式重试仅在快照和配置的缓存键一致时复用已验证阶段，避免重复费用。

## 删除与性能

- 删除来源前清理关联待办的修订历史，取消提醒；仅移除引用该来源的生活复盘，保留无关复盘。
- 原音精简、仅删除音频和删除整条记录，都将待删除路径与数据库变更一起提交。失败路径持久保留，在启动恢复时重试；仍被引用的文件不会删除。
- jobs 增加 automatic 字段、队列/来源索引，避免轮询时扫描 JSON；旧值按 JSON 解析回填。
- 任务中心后台查询，每 1.5 秒更新，有更多历史时可继续加载；应用公共任务指示也在后台查询。
- 搜索以数据库触发器维护来源变更版本，覆盖原文、标题、日期和记忆的增删改。索引与消费游标同事务提交；无变化时不遍历全部录音，删除也不会丢失失效通知。首次重建仍需处理全部来源。

## 完整备份与恢复

入口：高级设置 → 导出与工作流 → 完整备份与恢复。

完整备份 v3 保存手机已同步的音频、转写、标记元数据、记忆、待办、事件、反馈、修订历史、回顾、小时总结和删除标记。每份音频有长度及 SHA-256 校验，数据库快照与音频导出期间保持一致。

恢复先在暂存目录检查格式、路径、重复文件、解压上限、剩余空间和哈希，再显示录音数量供确认。仅导入空资料库；不覆盖或合并已有数据。数据库失败会回滚，并清理已搬入的文件；中断遗留文件由启动时的孤立文件恢复流程清理。音频路径重写到新安装私有目录，搜索索引和记忆索引可重建。

备份不包含 API Key、服务设置、配对凭据、云端任务、下载模型和声纹登记，也不包含手表未同步的音频。恢复不会开启自动云端处理；提醒需重新设置。ZIP 未加密，应保存于可信位置。旧版完整备份 v2、按日期的选择性导出不支持整包恢复，会显示明确说明。

## 验证

新增 WorkflowTests，使用隔离资料库和合成静音 WAV，验证授权关闭、手动任务独立、边界快照、删除修订历史、保留无关复盘、文件清理重试、增量索引、v12 迁移、完整备份往返、校验失败、路径穿越、非空资料库拒绝和失败回滚。

CI 增加双端构建与一次性 API 34 模拟器回归，Python CI 增加 Agent 评估测试。测试不访问实体设备，不调用外部模型。运行入口见 tests/android/run-regressions.py。
