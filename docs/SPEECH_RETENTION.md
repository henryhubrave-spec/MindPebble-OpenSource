# 手机本地 VAD

v0.2 在手机接入 Android VAD WebRTC 2.0.10（上游 WebRTC GMM，NORMAL 模式）。默认关闭，手表始终先采集完整 AAC。

开启后新接收的段排队做本地处理；也可在详情手动生成。Android 解码器转 PCM，重采样至 16kHz 单声道、20ms 帧判定；保留 500ms 前缓冲、800ms 后缓冲，合并间隔不超过 700ms 的段。手动重点标记保护前 3 秒、后 8 秒。输出 AAC 32kbps 与源/输出采样区间映射。

原件默认保留。只有用户另行确认“只保留语音”后，才将播放资产切换到派生音频并删除完整原件。完全无语音时可以仅留元数据，不产生空 AAC。同步协议记录 SPEECH_ONLY 状态，避免下一次传输又占回原音空间。手表原件仍保留，需另行清理。

映射支持回到原始时间，但目前转写没有逐词时间戳，不能宣称词级同步。VAD 可能误判远处、轻声、音乐或噪声；首次应用先试听对照，不保证语音零遗漏。保留原件时总存储可能增加，节省来自明确释放原件，不能据文件变小推断手表省电。

Android 模拟器原生解码/判定/编码实测：一份已经导出的本地 299.840 秒语音样本，生成 163.080 秒可播放副本，1,222,113 → 666,513 字节。仅代表该样本，未验证新 VAD 的语音召回率；没有向模型服务发送该样本。保留区间离线实验位于 `experiments/speech-retention`，不是手机运行时的替代品。
